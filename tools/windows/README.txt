LET'S GO FOR VROUVES / ΠΑΜΕ ΓΙΑ ΒΡΟΥΒΕΣ - for Windows
REVIVE8BIT - 2026 - VASPER

An Amstrad CPC game, with the emulator that runs it included.

TO PLAY
  Double-click Vrouves.exe. Nothing is installed: the first time, it unpacks the emulator
  and the game to %LOCALAPPDATA%\Vrouves (about 15 MB), then starts. The REVIVE8BIT screen
  and the picture of the game come first (10 seconds each, or press SPACE), then the game
  loads.

  Windows may warn that the program is from an unknown publisher (it isn't signed):
  choose "More info", then "Run anyway".

KEYS
  Cursor keys or Q A O P   move the cursor
  1 - 7                    choose a defender
  SPACE / RETURN           build
  S / DEL                  sell
  N                        next wave now
  H                        pause / continue
  ESC                      quit to the title (it asks: a second ESC quits, H plays on)
  L                        English / Greek, at any time
  M                        music on / off
  On the title screen: D chooses the difficulty, the right arrow turns the page.
  A joystick works too.

  F1 opens the emulator's menu, F2 switches to full screen, F10 quits.

The manual: MANUAL.pdf (English), MANUAL_GR.pdf (Greek).

THE EMULATOR
  Caprice32, https://github.com/ColinPitrat/caprice32 - free software under the GNU GPL,
  version 2 (licences/Caprice32-GPL.txt); its source code is at that address. It includes
  the Amstrad CPC system ROMs, which Amstrad allows to be distributed with emulators.
